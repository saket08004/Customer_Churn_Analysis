Customer churn costs businesses more than acquiring new ones. This project performs an end-to-end exploratory data analysis on a customer churn dataset to identify who is leaving, why, and what patterns predict attrition. Using Python in Jupyter Notebook, the analysis combines data wrangling with Pandas & NumPy and rich visual storytelling through Matplotlib & Seaborn — including bar charts, heatmaps, count plots, distribution plots, and trend charts — to transform raw data into clear, business-ready insights.
